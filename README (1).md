# PLATFORMER BY ALPHA

## About The Game
This is my first game — a simple but fun platformer made in Godot Engine with **10 levels** and lots of features!

## Controls
| Action | Keys |
|--------|------|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Jump | Space / Enter |
| Pause | Tab |

## What I Added Beyond The Tutorial
These are the things **I built myself** that were NOT in the tutorial:

- ✅ **10 custom levels** — designed and built all levels myself
- ✅ **Trap system** — added spike traps and danger zones (`trap.gd`)
- ✅ **Moving platforms** — coded moving platform mechanics (`moving_platform.tscn`)
- ✅ **Respawn system** — player respawns at checkpoints (`respawn.tscn`)
- ✅ **Settings menu** — volume and game settings (`setting.gd`)
- ✅ **Game Over screen** — custom game over UI (`gameover.gd`, `gameoverui.gd`)
- ✅ **Game End / Win screen** — separate ending scene (`game_end.gd`)
- ✅ **Custom sound effects** — added multiple audio files for jump, death, level complete
- ✅ **Screen fader** — smooth transitions between scenes (`fader.gd`)
- ✅ **Kill zones** — out-of-bounds death areas (`killzone.gd`)
